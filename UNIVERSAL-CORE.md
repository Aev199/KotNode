# Универсальный конструктор — первый шаг

Ветка `feat/universal-core` вводит самостоятельный черновик модели `AssemblyMark`. Старые `NodeMark`, `Project`, `Splice` и их отрисовка остаются прежними. Новый формат пока не используется панелью AutoCAD и не сохраняется в `.knproject.json`; `Json.Copy/Write/Read` проверяются отдельными тестами. Не нужно подменять старые марки новым форматом до реализации миграции и поддержки во всех потребителях.

- `PartDefinition` — тип, материал, позиция, плотность и геометрия детали, флаг учёта.
- `PartInstance` — UUID, ссылка на определение, независимое пространственное положение.
- `RigidPlacement` — правая ортонормированная система координат, без масштаба и отражений; миллиметры.
- `Specification()` — одна строка на учитываемое определение с экземплярами. Масса без округления; масса заготовок без припусков, вырезов и сварного металла. Число применений марки пока не умножается.
- Труба, прямоугольный лист, сектор цилиндрической оболочки. Сложные контуры, отверстия, двутавр, арматура, швы и оформление ещё не реализованы.

## Очередность

1. Подтвердить сборку и регрессии ядра в CI. Проверить эквивалентность криволинейного листа существующей накладке.
2. Добавить операции изменения/удаления деталей, произвольные контуры листов; определиться с миграцией старых марок без потери данных. Новый формат проекта должен отвергаться старым приложением явно, а не молча теряться при сохранении.
3. Добавить адаптер геометрии AutoCAD 2021 и палитру редактора; проверить вставку, выбор, копирование, поворот и редактирование.
4. Реализовать виды, сечения, устойчивые ссылки на элементы геометрии и независимое оформление. Масштаб модели 1:1; размеры и выноски не сбрасываются при перестроении.
5. Интегрировать позиции, спецификацию, ведомость стали, проект и совместное редактирование.
6. Двутавр, арматура, сварные швы, зависимости и пользовательские шаблоны.

## Проверка

`dotnet run --project tests/KotNode.Tests.csproj -c Release` запускает старые и новые проверки; `dotnet build src/Core/KotNode.Core.csproj -c Release -f net48` проверяет целевое ядро AutoCAD 2021. CI не требует DLL AutoCAD; полноценный плагин собирается отдельно на Windows через `build.ps1` с установленным AutoCAD 2021. В текущей среде .NET SDK отсутствует, C# тесты не исполнялись.
