# Универсальный конструктор — ядро 0.3 (в разработке)

Ветка `feat/universal-core` содержит CAD-независимые `AssemblyMark` и `AssemblyProject`. Старые `NodeMark`, `Project`, `Splice` и их отрисовка остаются прежними. Новый формат проекта пока не используется палитрой AutoCAD. Экспериментальный редактор хранит одну AssemblyMark непосредственно в DWG; все типы деталей ядра доступны через команды и палитру. Версия плагина не повышена.

## Реализовано

- `PartDefinition`: тип, материал, позиция, плотность, геометрия, флаг учёта.
- `PartInstance`: UUID, ссылка на определение, независимое пространственное положение.
- `RigidPlacement`: правая ортонормированная система координат, без масштаба и отражений; миллиметры.
- Добавление, копирование, перемещение, замена определения, отделение экземпляра от общей позиции, удаление.
- `Specification()`: одна строка на учитываемое определение с экземплярами. Масса нетто без припусков и сварного металла.
- Труба, прямоугольный лист, сектор цилиндрической оболочки.
- Лист с прямолинейными замкнутыми контурами, в том числе вогнутыми, с многоугольными и круглыми отверстиями; касания и наложения контуров запрещены. Замыкание неявное. Дуги внешнего контура пока не реализованы.
- Двутавр с параллельными полками: начальная выборка 43 профилей ГОСТ 35087-2024 (таблица 1), галтели по номинальному радиусу, табличная масса погонного метра. Полнота каталога и поправки не подтверждены. Старые вручную заданные профили читаются, но при редактировании требуется выбрать профиль из выборки.
- Арматура: пространственная осевая ломаная с касательными круговыми гибами. Радиус указан по оси стержня; длина учитывает вычет касательных и добавление дуг. Проверяется размещение соседних гибов, но не самопересечения всего тела, не нормативные радиусы оправок и не анкеровка.
- `AssemblyProject` (schema 2): совместное хранение старых и новых марок, единая уникальность UUID и шифров, применения и сводный расход материалов. Количество физических деталей = число экземпляров в марке × число применений. Неактивные применения и справочные детали исключаются.
- `AssemblyProject.FromLegacy`: явная миграция с сохранением идентичности старых марок и применений; новая история версий начинается с 0. Старый файл сохраняется без изменений. `AssemblyProjectStore` сохраняет в отдельный файл; блокировка, контроль версии кандидата и файла, резервная копия. Старый формат не перезаписывается. Конфликты пока на уровне всего проекта.

## Очередность

1. CI предыдущего этапа прошёл успешно (по сообщению пользователя).
2. Первый адаптер AutoCAD 2021 проверен пользователем. Расширенный набор деталей, вспомогательные группы и дерево состава реализованы, ожидают проверки по CONSTRUCTOR-PROTOTYPE.md.
3. Виды, сечения, устойчивые ссылки на элементы геометрии и независимое оформление. Масштаб модели 1:1; размеры и выноски не сбрасываются при перестроении.
4. Сварные швы и перенос вспомогательных чертежей на виды; развитие сортамента и редактирования контуров.
5. Интегрировать schema 2 во все потребители проекта, таблицы DWG, ведомость стали, диспетчер; только затем делать рабочую миграцию через UI. Добавить версии марок.
6. Геометрические зависимости и пользовательские шаблоны.

## Проверка

`dotnet run --project tests/KotNode.Tests.csproj -c Release` запускает старые и новые проверки; `dotnet build src/Core/KotNode.Core.csproj -c Release -f net48` проверяет целевое ядро AutoCAD 2021. CI не требует DLL AutoCAD; полноценный плагин собирается отдельно на Windows через `build.ps1` с установленным AutoCAD 2021. В текущей среде .NET SDK отсутствует. Выполнение CI для нового адаптера AutoCAD пока не подтверждено.
