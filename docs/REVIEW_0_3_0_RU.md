# Ревью KotNode 0.3.0 перед ручным тестом

Проверяемая исходная ревизия: 640be3df3367a4da528d31ae5f219362b517048e. Исправления выпускаются как 0.3.1, схема DWG не меняется.

## Найденные ошибки

| Приоритет | Сценарий и последствие | Исправление |
|---|---|---|
| P1 | При активном узле Б NAIMPORTVIEW мог принять плоский блок из вспомогательной графики узла А. Один объект получал двух владельцев; перемещение или удаление А затрагивало вид Б. | AttachSnapshot проверяет вспомогательные группы всех узлов. Перед перемещением/удалением узла и удалением вида проверяется эксклюзивное владение графикой. |
| P2 | Удаление вида через дерево стирало только внешний блок. Управляемые размеры и выноски в ModelSpace оставались без вида и переставали определяться как графика узла. | Единый метод удаления вида сначала стирает его управляемое оформление, затем блок. |
| P2 | NAMOVENODE вызывал Rebuild для старого вида без вложенного блока автогеометрии. Команда завершалась исключением и откатывала перемещение всего узла. | Старые виды перемещаются как существующая графика; обновляются их плоскость и метаданные, без принудительной миграции или перестроения. |
| P2 | У семейства без сохранённых видов начальная позиция таблиц вычислялась от мирового нуля. При вставке второго узла далеко от начала его таблицы оказывались возле первого. | Начальное размещение таблиц учитывает LayoutOrigin узла. |
| P3 | Одинаковые подписи «Обновить все» обозначали пересчёт всех узлов и обновление видов одного узла. Меню «Ещё» оставляло действия активными в пустом DWG. | Раздельные подписи «Все узлы DWG» и «Все виды узла»; пункты меню учитывают наличие активного узла. |

## Дополнительно проверено

- Регистрация всех 79 команд и наличие подписанных кнопок без повторных регистраций.
- Чтение старой одиночной марки, перенос в коллекцию и защитная запись для старых версий плагина.
- Изоляция параметров, деталей и таблиц при одинаковых внутренних ID экземпляров одного семейства.
- Сохранение активного узла отдельно от изменений соседних узлов.
- Пересчёт формул в локальных координатах семейства и возврат в координаты размещения; корректный перенос сохранённого семейства в другую точку.
- Транзакционность массового обновления и откат при исключении.

## Проверки и границы вывода

Сборка по API AutoCAD 2021, тесты ядра, проверка покрытия команд кнопками и Windows-проверка PaletteButton выполняются автоматически.

NAE2ETEST расширен нативными сценариями: запрет присвоения чужой вспомогательной графики; остановка действий при конфликтующих группах; совместное перемещение управляемого и старого вида; перенос нативного размера без двойного смещения; сохранение активного узла при изменении соседнего; удаление только собственных размеров вида. Эти сценарии компилируются, но не выполняются в обычном CI без AutoCAD.

Перед использованием на рабочем DWG требуется ручной прогон в AutoCAD на копии: две вставки одного семейства и одна другого, переключение узлов, изменение параметров, перемещение и удаление одного комплекта, удаление отдельного вида с оформлением, сохранение и повторное открытие. Визуальные проверки DPI и подрезки 0.2.8 остаются неподтверждёнными пользователем.
