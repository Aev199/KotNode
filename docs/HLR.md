# AutoCAD 2021: рабочий маршрут FLATSHOT

Испытание реального AutoCAD 2021 показало, что ObjectARX HLR не возвращает кривых даже для прямоугольного Solid3d (raw=0). Он отключён в основном маршруте построения видов. Исходник моста остаётся в репозитории только для возможной отдельной диагностики; CI не компилирует его.

`NAVIEW` создаёт изолированный DWG с проекционной ориентацией марки. `NASECTION` создаёт изолированную модель *за* выбранной секущей плоскостью. Оба действия НЕ создают готовую 2D-геометрию: пользователь выполняет штатный FLATSHOT в отдельном DWG, сохраняет файл, затем `NAFLATFINISH` импортирует плоский блок в исходный DWG и связывает его с маркой. В случае разреза `NAFLATFINISH` также добавляет контуры сечения и штриховки пересечённых деталей. `NACROSS` продолжает автоматически создавать чистое сечение без FLATSHOT.

Порядок:
1. В исходном DWG запустить `NAVIEW` или `NASECTION`, выбрать плоскость, задать имя, масштаб оформления и сохранить **новый** DWG для FLATSHOT.
2. Открыть новый DWG; должны быть только пространственные тела марки. ПСК `World`, вид `Top` (`PLAN` → `World`). Запустить `FLATSHOT`, выбрать вставку нового блока, нужный стиль невидимых линий, вставить **в 0,0,0**, единичный масштаб и угол 0.
3. Сохранить новый DWG. Вернуться в исходный DWG. Запустить `NAFLATFINISH`, выбрать подготовленный DWG и указать точку размещения.
4. Проверить положение, реальные габариты в миллиметрах, цвета линий и штриховку разреза, затем сохранить исходный DWG.

Импорт проверяет GUID марки и контрольный отпечаток геометрии, наличие ровно одного блока с кривыми в подготовленном файле, плоскость XY и масштаб без зеркалирования. Если модель изменилась после подготовки, импорт отклоняется. Блок привязан к марке с сохранённой плоскостью и именем как **ручной снимок**: при изменении 3D его нужно подготовить повторно. `NAUPDATEVIEWS` не перерисовывает ручные снимки (иначе результат утрачивался бы). Копии марки и вспомогательная графика не попадают в отдельную модель.

Часть функциональности зависит от ручного действия, поскольку FLATSHOT не имеет надёжного бездиалогового API в AutoCAD 2021. **Не утверждать, что виды обновляются автоматически.** Сверить первое и повторное построение до использования на рабочем чертеже.

Стандартная сборка CI теперь полностью управляемая (.NET Framework 4.8) и не скачивает ObjectARX SDK, не устанавливает C++/CLI, не компилирует HLR, выполняет тесты ядра и публикует артефакт из двух DLL.

Для отладки: `NPLOG`. Для раздельной проверки отсечения модели: `NAEXPORTCUT`. Для принятия обычного плоского блока в исходном чертеже: `NAIMPORTVIEW`.
