# KotNode 0.2.4 — работа с узлом и исправления тестирования

AutoCAD 2021, Windows x64; генератор представлений 21. Работа в пространстве модели, миллиметры, геометрия 1:1. Одна марка на DWG.

## Загрузка

1. Распаковать комплект целиком в постоянную папку. Полностью закрыть AutoCAD перед заменой DLL.
2. Открыть копию тестового DWG. Установить INSUNITS=4, TILEMODE=1, мировую ПСК.
3. NETLOAD → KotNode.AutoCAD.dll; KotNode.Core.dll должен лежать рядом.
4. NPVERSION должен показать 0.2.4 / генератор 21.
5. NAUPDATEVIEWS — обновить представления и оформление существующего узла. Сохранить DWG.

## Первый узел

NAFAMILY → выбрать семейство → задать шифр и параметры → вставить. Для вставки следующего семейства требуется новый пустой DWG. NACONSTRUCTOR открывает палитру состава и представлений. NAPARAMS меняет параметры и формулы; «Применить и перестроить» обновляет модель, виды и таблицы. NASOLVE повторяет пересчёт.

С нуля: NANEW, затем NAPIPE/NAPLATE/NAPOLYPLATE/NACURVED/NABEAM/NAREBAR. NAEDIT меняет описание и размеры выбранной детали. У общих экземпляров одна деталь; NADETACH отделяет экземпляр. Положения считываются после MOVE/ROTATE исходных 3D-деталей через NASYNC.

## Виды и разрезы

NAVIEW: направление → название → невидимые линии → масштаб оформления → точка вставки. NASECTION дополнительно задаёт секущую плоскость и штриховку. ThreePoints задаёт начало плоскости, направление вправо и верх; Normal/Reverse — сторону наблюдения. NAEDITVIEW меняет свойства и привязку плоскости к детали.

Плоские блоки видов перемещаются MOVE в мировой XY без поворота и масштабирования. Масштаб оформления задаётся через свойства вида; геометрия остаётся 1:1.

## Линии, швы и оформление

NALINEEDIT: Visible/Hidden/Suppress/Auto → Segment/Fragment/Edge → выбор. Fragment требует две границы участка. Enter применяет группу, Esc отменяет её. NALINERESET снимает правки.

NAWELD: тип Site/Factory/Hidden → область Segment/Fragment/Edge → катет → выбор кромки → сторона → Enter. NAWELDRESET удаляет швы.

**NAWELDEDIT**: указать ряд крестиков/ресничек существующего шва на исходном виде. В форме изменить катет, тип, сторону и дополнительный отступ в миллиметрах. Положительный и отрицательный отступы смещают графику по нормали к кромке. Привязка к кромке и ID шва сохраняются. Катет и выноска обновляются вместе. Отступ — только оформление, он не перемещает физический шов на разрезе. Команда доступна также через ПКМ на кнопке «Сварные швы» палитры.

Для продольных начальных/конечных кромок криволинейной накладки на трубе шов показывается на пересекающих его разрезах заполненным срезом. В поперечном сечении это треугольник с заданным катетом. Проверяется наличие трубы в месте контакта; в зазоре между торцами труб треугольник не создаётся. Кромка на другом радиусе, гладкий силуэт или произвольное соединение сами по себе не определяют физический шов: автоматическое распространение для них не заявляется. Оно применяется к конкретному экземпляру накладки и не назначает швы остальным экземплярам автоматически. Флаг формы позволяет отключить срез.

NADIM добавляет размер; NAPOS — позицию; NAWELDLEADER — выноску шва; NAAXIS — оси; NASECTIONMARK — обозначение разреза. Размерные линии, текст и полки можно перемещать ручками. В 0.2.3 размер использует нативные засечки DIMTSZ с продолжением DIMDLE вместо зазора под пользовательский блок стрелки.

Выноска углового шва приведена к варианту для чертежей КМ: числовой катет на подчёркнутой полке, монтажный/заводской характер показывает графика шва. Убраны равносторонний Unicode-треугольник и «(монт.)». Основание: ГОСТ 21.502-2016, п. 4.8 и таблица А.2. Это не полное обозначение типа соединения по ГОСТ 2.312 и ГОСТ на сварные соединения.

Дополнительную произвольную графику добавлять через BEDIT внешнего NA_VIEW_SHELL, не вложенной автогеометрии. Она сохраняется при обновлении, но не получает ассоциативности к размерам детали.

## Пример: линейный зазор между накладками

Здесь C_gap — расстояние в свету по прямой хорде между соседними кромками накладок на радиусе наружной поверхности трубы. Это не длина дуги; расстояние между проекциями на продольном виде может отличаться. Пример — штатное семейство «Стык труб на накладках», N_plates >= 2.

1. Открыть NAPARAMS → «Параметры узла».
2. «+ Параметр»: имя C_gap, описание «Между накладками в свету», значение 50, единицы мм, формула пустая.
3. У существующего параметра Angle заменить формулу на:

```
360 / N_plates - 2 * asin(C_gap / D)
```

4. Нажать «Применить и перестроить». Новую привязку размеров создавать не нужно: штатная привязка CurvedPlate.AngleDeg уже использует Angle.
5. Для D=820, N_plates=4 и C_gap=50 получается Angle=83.0083727352 градуса. При смене D зазор остаётся 50 мм, изменяется угол накладки.
6. Сохранить DWG и выполнить NAFAMILYSAVE, чтобы формула попала в собственное семейство.

asin в формулах KotNode возвращает градусы. Для положительного угла накладки требуется 0 <= C_gap < D * sin(180 / N_plates). Для одной накладки этот параметр не определяет междетальный зазор — угол задаётся отдельно. gap в штатном семействе продолжает управлять зазором между торцами труб.

## Ведомости, семейства и проект

NASPEC/NAVRS вставляют таблицы; NAUPDATEVIEWS/NAUPDATETABLES обновляют их; NAEXPORTCSV выгружает состав. Включаются детали с флагом спецификации, масса без припусков и наплавленного металла. NAFAMILYSAVE сохраняет состав, параметры и оформление. Новая вставка через NAFAMILY → «Открыть .knfamily.json».

NPROJECT2 создаёт реестр проекта; NAPROJIMPORT переносит марку из текущего DWG. В «Применениях» задать участок, число узлов и флаг включения. NAPROJVRS создаёт сводную таблицу. После изменения марки повторить импорт, затем NAPROJUPDATE.

## Проверки перед выпуском

0.2.3: сборка по API AutoCAD 2021 и независимые тесты ядра. Добавлены 19 проверок редактирования шва, геометрии среза, границ распространения и формулы зазора. Расширен NAE2ETEST для нативных размеров и связанных срезов. Новые сценарии внутри AutoCAD в текущей среде не выполнялись: окончательный вид засечек, подчёркивания MLeader и заполнения треугольника нужно подтвердить на Windows.

## Нестабильное открытие «Параметры/формулы» — 0.2.4

После сообщения о зависании пользователь подтвердил, что окно снова открывается. Причина не воспроизведена и не считается установленной.

Добавлены защитные изменения: открытие NAPARAMS читает сохранённую марку без синхронизации пространства модели; DWG синхронизируется при применении. Модальное окно имеет явного владельца — главное окно AutoCAD — и не восстанавливает старую позицию. Таблицы используют фиксированные ширины и загрузку строк на OnLoad без автоматического Fill-пересчёта столбцов.

Этапы открытия немедленно записываются в `%LOCALAPPDATA%/KotNode/Logs/trace-NAPARAMS-*.log`. Путь выводится при запуске команды, а NPLOG показывает последний журнал в текущем сеансе. Если AutoCAD пришлось завершить, файл сохраняет последний пройденный этап. Если последнее сообщение «окно показано», отдельно проверяются фокус и расположение модального окна; это не доказательство зависания вычислений.

Эти меры не являются подтверждением устранения исходного плавающего зависания. Требуется повторная проверка открытия окна в реальном AutoCAD.
