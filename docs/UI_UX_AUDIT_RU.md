# KotNode 0.3.0 — аудит UI/UX и покрытия инструментов

Проверены обработчики палитр, зарегистрированные команды, выбор контекста узла и доступ к редким инструментам. Визуальный прогон в настоящем AutoCAD 2021 в среде разработки не выполнялся.

## Найденные проблемы и внесённые изменения

| Проблема | Изменение |
|---|---|
| Один DWG ошибочно трактовался как одна марка | Коллекция узлов с устойчивым активным идентификатором |
| Непонятно, какой узел редактируется | Верхний список узлов и подпись «Активный»; выбор узла по графике |
| Повторная вставка семейства пересекалась с первой и могла возвращаться при пересчёте | Точка вставки и отдельное размещение относительно координат формул |
| Заголовок и кнопки конкурировали за ширину | Вертикальная раскладка заголовка, перенос верхних кнопок, увеличение минимального размера |
| Часть действий была только в командной строке или ПКМ | Каталог с отдельными подписанными кнопками для всех команд, поиск и категории |
| Редактирование общего катета и создание шва сечения были спрятаны в ПКМ | Прямые кнопки в поисковом каталоге |
| Подрезка вытеснила синхронизацию из основной сетки | Оба инструмента доступны в каталоге, NASYNC также в меню «Ещё» |
| Команды могли запускаться без узла и заканчиваться ошибкой | Кнопки инструментов с контекстом узла отключаются при пустом DWG |
| Не было перемещения всего комплекта | NAMOVENODE перемещает детали, виды, оформление и таблицы |
| Диагностические тесты изменяют рабочий DWG | Предупреждение перед их запуском из каталога |
| Новая команда могла остаться без кнопки | Автоматическая сверка регистрации команд с каталогом в CI |

## Выполненная проверка и оставшийся ручной прогон

Автоматическая проверка подтверждает наличие 79 команд в каталоге и отсутствие устаревших либо повторных кнопок. Тесты модели проверяют независимость данных повторных и разных семейств, сохранение размещения при пересчёте, сериализацию и выбор активного узла. Windows-проверка PaletteButton проверяет обычные и клавиатурные нажатия и открытие меню без модели.

Ручной прогон в AutoCAD: проверить палитру при DPI 100/150/200%, длинные шифры/названия, закрепление и повторный запуск; вставить два варианта одного семейства и узел другого семейства; переключать активный узел через список и графику; изменить параметры каждого; переместить целый комплект; сохранить/открыть DWG; сохранить один узел как семейство и вставить ещё раз. Удаление одного узла проверять на копии DWG, убедившись в сохранности соседних узлов.
