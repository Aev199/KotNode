# Исправление 0.2.1

## Найденная ошибка

В версии 0.2 метод снятия объединений ячеек обращался к свойствам результата `Cell.GetMergeRange()` без проверки на null. В API AutoCAD null является корректным результатом для обычной, необъединенной ячейки.

При вставке полного комплекта этот метод вызывается для новой спецификации; обычные ячейки приводили к NullReferenceException. Вся транзакция откатывалась, а оболочка команды показывала только локализованное сообщение без стека.

Исправление: обычные ячейки пропускаются, реальные объединения снимаются как раньше. Тот же исправленный метод используется при NPUPDATE существующих таблиц.

Документация API: https://help.autodesk.com/cloudhelp/2026/ENU/OARX-ManagedRefGuide/files/OARX-ManagedRefGuide-Autodesk_AutoCAD_DatabaseServices_Cell_GetMergeRange.html

## Диагностика

При ошибке команда теперь выводит версию DLL, тип исключения, текущий этап отрисовки и путь к журналу. В журнал записываются полный стек, вложенные исключения и последовательность этапов; отправки данных куда-либо нет.

Журналы: `%LOCALAPPDATA%\KotNode\Logs`.

- **NPVERSION**: показать фактически загруженную версию и путь DLL. Ожидается **0.2.1.0**.
- **NPLOG**: показать путь последнего журнала ошибок в этом сеансе.

## Установка

Полностью закройте AutoCAD, распакуйте архив в отдельную папку и загрузите новый `plugin/KotNode.AutoCAD.dll` через NETLOAD. `KotNode.Core.dll` должен лежать рядом. Запустите NPVERSION, затем NPROJECT и повторите вставку.

Если ошибка повторится, скопируйте сообщение с этапом и содержимое файла, путь которого показывает NPLOG. Это позволит определить точный следующий сбой без догадок.

## Проверки

Регрессионная проверка компилирует и исполняет **тот же исходный метод Unmerge**, что и плагин, с небольшой подменой Table/Cell API. Подмена повторяет документированный null-результат обычной ячейки. Проверяются обычная таблица, смешанная таблица с заголовком/подвалом, повторное обновление и пустая таблица. Отдельно проверяется запись диагностики и поведение при невозможности записать журнал.

Также повторяются 22 проверки ядра и сравнение с LISP на 112 наборах геометрии / 56 компоновках. AutoCAD в среде разработки отсутствует; нативное выполнение исправления требует повторной вставки на Windows.
