# Архитектура 0.2

Проект → марки → состав и применения сохраняется из 0.1. Изображения не определяют количество изделий. Параметры марки и ее редакция отделены от версии оформления.

`Core/Drafting.cs` вычисляет план видов: примитивы, физические сварные кромки, проекции рядов, размеры и выноски. План не зависит от AutoCAD; он сравнивается с исполнением эталонного LISP 0.7.

`AutoCAD/Drawing.cs` преобразует план в нативные сущности. Сами блоки видов, размеры, выноски и таблицы связаны через XRecord. Каждый размер и выноска имеют постоянный ключ внутри вида. При обновлении существующие объекты изменяются на месте; исчезнувшие роли удаляются, новые создаются.

Метаданные размера сохраняют предыдущий план для переноса ручных смещений. Для MOVE группы учитывается фактическое перемещение точек размера, чтобы не применять перенос вида второй раз. Виды группируются только с размерами; выноски и таблицы остаются самостоятельными.

Положение и ширина существующих таблиц сохраняются; расчетное содержимое и служебные объединения обновляются. Локальная ВРС и спецификация привязаны к марке, глобальная ведомость — к проекту.

Следующие этапы после прогона AutoCAD: исправления фактического отображения, навигация по связанным DWG, расширение состава на произвольные детали, новые типы соединений, история редакций и интеграция с паспортом проекта. Миграция LISP-узлов пока не реализована.
