# Экспериментальный конструктор AutoCAD 2021

Сборка: GitHub Actions, артефакт `KotNode-AutoCAD2021-experimental` (оба DLL должны находиться рядом).
Для локальной сборки: `powershell -ExecutionPolicy Bypass -File build.ps1`.
Закройте прежний сеанс AutoCAD, распакуйте DLL в доверенную папку, откройте новый тестовый DWG и выполните NETLOAD для KotNode.AutoCAD.dll.

## Команды

| Команда | Действие |
|---|---|
| NACONSTRUCTOR | Палитра |
| NANEW | Создать одну марку в текущем DWG |
| NAPIPE | Труба вдоль локальной Z |
| NAPLATE | Лист в локальной XY, толщина по Z |
| NAEDIT | Свойства определения; обновление всех его экземпляров |
| NACOPY | Копия экземпляра с общей позицией и сохранением ориентации |
| NADETACH | Новая независимая позиция для одного экземпляра |
| NADELETE | Удаление экземпляра (и определения, если не осталось экземпляров) |
| NASYNC | Записать положения после MOVE/ROTATE/ROTATE3D |
| NAINFO | Состав и масса в командной строке |
| NAREPAIR | Восстановить отсутствующие управляемые экземпляры в последних сохранённых положениях |

## Ручной тест

1. Новый DWG, INSUNITS=4, TILEMODE=1, UCS World. NETLOAD. NACONSTRUCTOR, NANEW, марка УР-1.
2. NAPIPE: 820×12, длина 1000; справочная. Начало 0,0,0. Посмотреть в изометрии и убедиться, что труба полая.
3. NAPLATE: 500×200×12, позиция 1, учитывать. Начало 450,0,0. NAINFO: 1 лист 9,42 кг, труба не учитывается.
4. NACOPY: выбрать лист, указать 450,300,0. NAINFO: 2 листа по 9,42 кг, 18,84 кг.
5. NAEDIT: изменить толщину одного листа на 20; оба обновляются, суммарно 31,4 кг.
6. NADETACH: выделить второй лист и задать позицию 2. NAEDIT: вернуть ему толщину 12. NAINFO: 15,7 + 9,42 = 25,12 кг.
7. MOVE, ROTATE, ROTATE3D управляемого блока, NASYNC. Сохранить, закрыть и открыть DWG; проверить положение и состав. Сменить UCS и добавить трубу, проверить направление оси.
8. NADELETE, UNDO, REDO; проверить геометрию и количество. Отменить окно NAEDIT и точку вставки; модель должна оставаться неизменной.
9. На отдельной копии DWG: обычная COPY не учитывается; обычная ERASE управляемого блока вызывает диагностику. NAREPAIR восстанавливает удалённое по последнему сохранённому положению. SCALE или MIRROR не должны молча менять массу/ориентацию модели; при недопустимом преобразовании отменить его.
10. Открыть второй DWG: его марка не должна смешиваться с первым. Открыть сохранённый DWG без плагина: геометрия должна быть видна.
11. Проверить прежние NPROJECT/NPPLACE на отдельном файле.

## Ограничения прототипа

- Одна марка на DWG, нет связи со schema-2 проектом и общего диспетчера новых марок.
- Только труба и прямоугольный лист в интерфейсе; другие типы есть в ядре.
- Нет автоматических видов, сечений, размеров, выносок и таблиц. NAINFO — текстовая спецификация.
- Вставка в пространство модели, миллиметры, без масштабирования и зеркального отражения.
- Нативные MOVE/ROTATE сохраняют положение в модели на следующей успешной изменяющей команде или NASYNC. NAINFO не записывает данные.
- Нельзя редактировать внутреннюю геометрию через BEDIT/REFEDIT/EXPLODE, STRETCH; такие операции не синхронизируются. COPY создаёт неуправляемую копию, не включаемую в спецификацию.
- Старые определения блоков после редактирования могут оставаться до PURGE; это позволяет не изменять несвязанные копии.
- Успешная сборка не подтверждает работу ACIS и API в запущенном AutoCAD. Не использовать на рабочих чертежах до ручного теста.
