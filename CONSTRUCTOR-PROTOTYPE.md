# Экспериментальный конструктор AutoCAD 2021

Сборка: GitHub Actions, артефакт `KotNode-AutoCAD2021-experimental` (оба DLL должны находиться рядом).
Для локальной сборки: `powershell -ExecutionPolicy Bypass -File build.ps1`.
Закройте прежний сеанс AutoCAD, распакуйте DLL в доверенную папку, откройте новый тестовый DWG и выполните NETLOAD для KotNode.AutoCAD.dll.

## Команды

| Команда | Действие |
|---|---|
| NACONSTRUCTOR | Палитра |
| NANEW | Создать одну марку в текущем DWG |
| NAPIPE | Труба вдоль локальной Z |
| NAPLATE | Лист в локальной XY, толщина по Z |
| NAPOLYPLATE | Лист по замкнутой полилинии, отверстия по полилиниям и окружностям |
| NACURVED | Криволинейный лист — сектор цилиндра |
| NABEAM | Двутавр с параллельными полками |
| NAREBAR | Стержень по точкам с радиусами гиба |
| NAAUX | Группа вспомогательной графики |
| NAREFRESH / NASELECT | Дерево состава и выбор на чертеже |
| NAEDIT | Свойства определения; обновление всех его экземпляров |
| NACOPY | Копия экземпляра с общей позицией и сохранением ориентации |
| NADETACH | Новая независимая позиция для одного экземпляра |
| NADELETE | Удаление экземпляра (и определения, если не осталось экземпляров) |
| NASYNC | Записать положения после MOVE/ROTATE/ROTATE3D |
| NAINFO | Состав и масса в командной строке |
| NAREPAIR | Восстановить отсутствующие управляемые экземпляры в последних сохранённых положениях |

## Ручной тест

1. Новый DWG, INSUNITS=4, TILEMODE=1, UCS World. NETLOAD. NACONSTRUCTOR, NANEW, марка УР-1.
2. NAPIPE: 820×12, длина 1000; справочная. Начало 0,0,0. Посмотреть в изометрии и убедиться, что труба полая.
3. NAPLATE: 500×200×12, позиция 1, учитывать. Начало 450,0,0. NAINFO: 1 лист 9,42 кг, труба не учитывается.
4. NACOPY: выбрать лист, указать 450,300,0. NAINFO: 2 листа по 9,42 кг, 18,84 кг.
5. NAEDIT: изменить толщину одного листа на 20; оба обновляются, суммарно 31,4 кг.
6. NADETACH: выделить второй лист и задать позицию 2. NAEDIT: вернуть ему толщину 12. NAINFO: 15,7 + 9,42 = 25,12 кг.
7. MOVE, ROTATE, ROTATE3D управляемого блока, NASYNC. Сохранить, закрыть и открыть DWG; проверить положение и состав. Сменить UCS и добавить трубу, проверить направление оси.
8. NADELETE, UNDO, REDO; проверить геометрию и количество. Отменить окно NAEDIT и точку вставки; модель должна оставаться неизменной.
9. На отдельной копии DWG: обычная COPY не учитывается; обычная ERASE управляемого блока исключает его из отображаемого состава; после NAREFRESH/NASYNC или следующего успешного изменения удаление сохраняется в модели. NAREPAIR восстанавливает отсутствующие экземпляры только до сохранения удаления. SCALE или MIRROR не должны молча менять массу/ориентацию модели; при недопустимом преобразовании отменить его.
10. Открыть второй DWG: его марка не должна смешиваться с первым. Открыть сохранённый DWG без плагина: геометрия должна быть видна.
11. Проверить прежние NPROJECT/NPPLACE на отдельном файле.

## Ограничения прототипа

- Одна марка на DWG, нет связи со schema-2 проектом и общего диспетчера новых марок.
- Поддерживаются все шесть типов деталей ядра. Для двутавра есть начальная выборка 43 профилей ГОСТ 35087-2024 (Б, Ш, К), номинальная геометрия с радиусами сопряжения и табличная масса. Поправки стандарта и остальной сортамент ещё не сверены; рабочее применение не подтверждено. Арматура строится отдельными телами прямых и кривых участков одного блока.
- Нет автоматических видов, сечений, размеров, выносок и таблиц. NAINFO — текстовая спецификация. Вспомогательный чертёж — именованная группа нативных примитивов, исключённая из массы; перенос на виды ещё не реализован.
- Вставка в пространство модели, миллиметры, без масштабирования и зеркального отражения.
- Нативные MOVE/ROTATE сохраняют положение в модели на следующей успешной изменяющей команде или NASYNC. NAINFO не записывает данные.
- Нельзя редактировать внутреннюю геометрию через BEDIT/REFEDIT/EXPLODE, STRETCH; такие операции не синхронизируются. COPY создаёт неуправляемую копию, не включаемую в спецификацию.
- Старые определения блоков после редактирования могут оставаться до PURGE; это позволяет не изменять несвязанные копии.
- Успешная сборка не подтверждает работу ACIS и API в запущенном AutoCAD. Не использовать на рабочих чертежах до ручного теста.

## Дополнительные тесты второго этапа

- NAPOLYPLATE: внешний контур можно выбрать как одну замкнутую полилинию (LWPOLYLINE/2D/3D) или замкнутую цепочку LINE. Внешний прямоугольник 500×200, отверстие Ø40 строго внутри, толщина 12: масса около 9,302 кг. Исходные контуры остаются; их можно удалить или перенести на выключенный слой. Проверить вогнутый контур, два отверстия, отклонение пересечений; дуги и изменение контура после создания пока не поддержаны. Плоскость контура должна быть параллельна XY текущей ПСК.
- NACURVED: Rвн=410, t=12, L=500, 60°; масса около 20,518 кг. Проверить сектор 270° и полное кольцо, редактирование угла.
- NABEAM: выбрать 40Ш2, L=1000, учитывать: 106,70 кг; h=390, b=300, s=10, t=16, r=22. Проверить изменение профиля и длины через NAEDIT.
- NAREBAR: в мировой ПСК точки 0,0,0 → 200,0,0 → 200,200,0, Enter; Ø16, радиус по оси 64, проверить плавное соединение участков, длину 372,531 мм, массу около 0,588 кг. Проверить пространственный гиб, невозможные радиусы, сохранение и редактирование. Точки траектории пока не редактируются; радиусы и диаметр редактируются.
- NAAUX: выбрать линии, штриховку или обычный блок; проверить появление группы в дереве, неизменность массы, сохранение и повторное открытие DWG. Управляемая деталь не должна приниматься в группу.
- Дерево: выбрать определение и экземпляр, двойной щелчок или кнопка выбора; проверить выделение на чертеже, обновление после операций и переключения DWG (кнопка «Обновить дерево»).
- Повторить тесты первого этапа и UNDO/REDO для новых типов. Состав группы вспомогательной графики пока управляется стандартными средствами GROUP/UNGROUP AutoCAD.

## Регрессия удаления

- Удалить через ERASE один из двух экземпляров позиции. Дерево и NAINFO должны показать один экземпляр; новая деталь создаётся без NAREPAIR. Проверить UNDO/REDO до сохранения и после NAREFRESH, затем SAVE/OPEN. После удаления последнего экземпляра позиция исчезает. NAREFRESH сохраняет очистку отсутствующих экземпляров. Кнопка «Удалить из дерева» удаляет выбранный экземпляр либо все экземпляры выбранной позиции с подтверждением. Обычные COPY и EXPLODE не создают управляемых деталей. OOPS после сохранения удаления не является поддерживаемым способом восстановления марки.
